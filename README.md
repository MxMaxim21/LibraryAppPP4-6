# LibraryApp

Консольное приложение на C# (.NET Framework 4.8) для учёта книг в библиотеке.
Учебный проект по практической подготовке: отладка, инспекция кода, документирование результатов тестирования.

## Возможности

- добавление книги в библиотеку (`AddBook`);
- выдача книги читателю (`BorrowBook`) с проверкой, что книга существует и доступна;
- возврат книги (`ReturnBook`) с проверкой, что книга была выдана;
- поиск книги по идентификатору (`FindBook`).

## Структура

| Файл | Назначение |
|---|---|
| `Book.cs` | Класс `Book`: `Id`, `Title`, `Author`, `IsAvailable` |
| `Library.cs` | Класс `Library`: список книг и операции над ним |
| `Program.cs` | Метод `Main`: демонстрация позитивных и негативных сценариев |
| `TEST_REPORT.md` | Отчёт о тестировании: дефекты, инспекция кода, итоги |

## Требования

- Windows;
- Visual Studio 2019 или новее с компонентом «Разработка классических приложений .NET» (.NET Framework 4.8).

## Запуск

1. Клонируйте репозиторий:
   ```
   git clone <https://github.com/MxMaxim21/LibraryAppPP4-6>
   ```
2. Откройте файл `LibraryApp.sln` в Visual Studio.
3. Нажмите **Ctrl+F5** (запуск без отладки) или **F5** (запуск с отладкой).
4. Для выхода нажмите любую клавишу в окне консоли.

## Отладка и тестирование

Описание найденных дефектов, результатов инспекции кода и итогов повторного тестирования — в файле [TEST_REPORT.md](TEST_REPORT.md).
Исходная версия кода с намеренно необработанными граничными случаями сохранена в истории коммитов (`release class book`).
